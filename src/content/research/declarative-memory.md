- Researched declarative memory (a semantic knowledge retrieval system) for the ACT-R cognitive architecture.
- Architected a new declarative memory system using CUDA, thread pools, parsers, and inter-process communication.
- Continued the project between summers as undergraduate thesis research.
- Result: parallelized declarative retrievals, yielding a 100x speedup over the fastest existing implementation.

**Collaborators:** Tarek Taha (University of Dayton), Scott Douglass (Air Force Research Lab), Tanvir Atahary (Air Force Research Lab)
